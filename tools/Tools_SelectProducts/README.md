# Tools for Select Products

跨境电商跟卖选品利润辅助计算工具 - Microsoft Edge 浏览器扩展

## 功能概述

该扩展工具帮助跨境电商卖家快速计算产品利润，支持输入产品信息后自动计算运费和利润，同时提供灵活的设置选项。

### 主要功能

- **产品信息输入**：支持输入中文名、售价、长宽高、重量、采购价、链接、ASIN等信息
- **运费计算**：基于自定义运费模板（法国/英国）自动计算运费
- **利润计算**：自动计算产品利润，支持成本冗余设置
- **体积重计算**：支持长×宽×高÷除数的体积重计算方式，除数可配置（默认8000）
- **尺寸限制校验**：自动校验产品尺寸是否符合法国/英国的物流限制要求
- **数据管理**：支持保存、查看、清空已输入的产品数据
- **Excel导出**：支持将数据导出为Excel文件
- **小窗模式**：点击按钮或使用快捷键打开独立小窗口，方便随时查看
- **快捷键**：支持自定义快捷键打开主窗口和小窗
- **设置管理**：灵活配置汇率、运费、冗余、尺寸限制和评分等参数

## 安装说明

### 开发模式安装

1. 打开 Microsoft Edge 浏览器
2. 输入 `edge://extensions/` 进入扩展管理页面
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目目录下的 `edge` 文件夹

## 使用说明

### 主弹窗页面

在浏览器工具栏点击扩展图标打开主弹窗，输入以下产品信息：

| 字段 | 说明 |
|------|------|
| 中文名 | 产品中文名称 |
| 售价€ | 产品在目标市场的售价（欧元） |
| 最长边 | 产品最长边尺寸（cm） |
| 次长边 | 产品次长边尺寸（cm） |
| 最短边 | 产品最短边尺寸（cm） |
| 重量kg | 产品重量（千克） |
| 采购价 | 产品采购价格（人民币） |
| 链接 | 产品来源链接 |
| ASIN | Amazon产品ASIN码 |

输入完成后系统会自动计算：
- **运费**：根据产品尺寸和重量自动计算（运:xxx）
- **利润**：销售价 × 67% × 汇率 - 采购价 - 快递费（利:xxx）

### 快捷操作

| 按钮 | 说明 |
|------|------|
| ⊞ | 小窗模式：打开独立小窗口，方便随时查看 |
| 运费模板 | 选择法国或英国运费模板 |
| 保存 | 保存当前产品数据 |
| 查看 | 查看所有已保存数据 |
| 设置 | 进入设置页面 |
| 清空 | 清空当前输入数据 |

### 快捷键

在浏览器扩展管理页面的"键盘快捷方式"中配置：

| 快捷键 | 功能 | 默认值 |
|--------|------|--------|
| 打开主窗口 | 打开扩展主弹窗 | Alt+1 |
| 打开小窗 | 打开独立小窗口 | Alt+2 |

### 设置页面

点击"设置"按钮进入设置页面，可配置以下选项（按顺序）：

#### 汇率设置
- 欧元汇率（EUR/CNY）：默认7.5
- 英镑汇率（GBP/CNY）：默认9.2

#### 运费设置
支持法国和英国两个国家的运费配置：
- 重量范围（kg）：支持多个重量段配置
- 挂号费（元）
- 运费（元/kg）
- 其他费用（元）
- 新增重量段功能

#### 冗余设置

##### 重量冗余
- **比例模式**：按重量百分比添加冗余
- **固定模式**：按固定克数添加冗余（默认50g）

##### 尺寸冗余
- 长度冗余（默认5cm）
- 宽度冗余（默认5cm）
- 高度冗余（默认5cm）

##### 成本冗余
- **比例模式**：按成本百分比添加冗余
- **固定模式**：按固定金额添加冗余（默认5元）

##### 体积重计算
- 体积重除数（默认8000）
- 计算公式：体积重(kg) = 长×宽×高(cm) ÷ 除数

#### 快捷键设置
- 打开浏览器键盘快捷方式设置页面

#### 尺寸限制设置

##### 法国尺寸限制
- 最长边限制：60cm
- 最小尺寸限制：最长边>15cm，次长边>10cm
- 长+宽+高限制：90cm

##### 英国尺寸限制
- **0-2KG（主要地区）**：
  - 最长边限制：≤60cm
  - 最小尺寸限制：最长边>21cm，次长边>10cm
  - 三边长度限制：60cm×40cm×40cm
  - 体积限制：<0.04m³
- **2-15KG（主要地区）**：
  - 最长边限制：≤120cm
  - 最小尺寸限制：最长边>21cm，次长边>10cm
  - 长+宽+高限制：≤150cm
  - 体积限制：<0.04m³

#### 评分设置
用于产品评分计算的各项权重（总和应为100%）：
- 发货方式
- 评分
- 评分数量（本国）
- 上架时间
- 最近月销量
- 物流时效（天）
- 货源数量
- 印象分
- 预估广告费
- 竞争情况
- 体积重量
- 售价潜力
- 差异化空间

### 数据查看页面

点击"查看"按钮进入数据查看页面，可查看所有已保存的产品数据，并支持导出为Excel文件。

## 技术实现

### 运费计算规则

基于设置页面配置的运费模板：

1. **体积重计算**：体积重(kg) = 长×宽×高(cm) ÷ 体积重除数
2. **计费重量**：实际重量和体积重取较大值
3. **运费计算**：根据计费重量匹配对应的重量段，运费 = 挂号费 + 计费重量 × 运费(元/kg) + 其他费用

### 尺寸限制校验

- 尺寸冗余：输入的尺寸 + 冗余值 = 实际校验尺寸
- 三边排序：最长边 ≥ 次长边 ≥ 最短边
- 规则匹配：根据选中的运费模板（法国/英国）和重量范围匹配对应的尺寸限制

### 数据存储

使用 `chrome.storage.local` 存储产品数据和设置配置：
- 设置项持久化保存
- 产品数据支持保存和查看

### 窗口管理

- **小窗模式**：使用 `chrome.windows.create` 创建独立窗口，类型为 `popup`（无浏览器标签页和地址栏）
